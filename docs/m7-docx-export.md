# M7 Word 导出接入记录

2026-09-09：复杂内容转换与正式入口已接通。使用「导出文档 → Word 文档（.docx）」，查看转换说明后下载点击时的文档快照。取消弹窗不会下载，切换文档或卸载会取消旧任务。

这是 DOCX 导出功能交付，不代表 M7 所有后续能力均已验收。Microsoft Word/WPS 本体尚未验证；没有新增 DOCX 导入、实时分页、批注或修订。

## 内容范围

| 内容 | 输出行为 |
| --- | --- |
| 段落、标题、文字 | 保留对齐、行距、字符缩进、颜色、字号、背景、加粗、斜体、下划线、删除线和超链接；字号取最近半磅，数值字重转换为常规/加粗时提示 |
| 列表 | 原生编号，独立列表重新编号，保留起始数字、字母/罗马编号、混合嵌套及多段列表项；超过九层时提示 Word 编号层级限制 |
| 引用、分隔线 | 引用缩进、底色、左边线；分隔线使用段落边框 |
| 表格 | 横纵合并、列宽、底色、嵌套表格、列表、图片、代码与公式；超宽时等比收窄并提示；长行允许跨页，连续且未纵向合并的表头标记为重复表头 |
| 图片 | PNG/JPEG 内嵌原始字节；WebP 转 PNG 保留透明度，动画仅保留静态画面；按正文/单元格宽度和单页高度等比限制 |
| 公式 | 安全的 KaTeX MathML 转 OMML，支持常用分式、根式、上下标、上下限、矩阵和重音；不能转换的整式保留完整 LaTeX，并提示使用 HTML/打印查看排版 |
| 代码 | 复用已有语言与着色器，采用打印配色，保持空行、中文和源码字符；超过单块 20000 / 累计 100000 字符着色预算时保留全文并提示 |
| 附件 | 保留文件名和字节数，不在 DOCX 嵌入附件；下载前提示使用 Mewoc 文件做完整备份 |
| 纸张与分页 | A4 横竖方向、毫米页边距；分页应用到后续内容段前，保留连续/末尾分页；表格内分页由 Word 的表格排版决定并提示 |

表格最多 1000 列、100000 个展开格位；重叠、越界或缺格明确拒绝，避免错误修复导致内容丢失。WebP 解码最多四千万像素，临时 Canvas 最多四百万像素，缩小会提示。下载不含临时 URL、选区、图片手柄或编辑控件。

## 数据与异步边界

`ExportActions → docx-file → 动态导入 docx-export → DocxExportDialog → downloadDocument`。

`docx-file` 在第一次 await 前复制并校验文档、固定 Blob 引用。Blob 不可变，无需复制整份图片字节。转换器不访问编辑器 DOM、IndexedDB 或会话 URL，也不修改原文档。表格和公式转换保留在同模块工具中。

`ExportActions` 保留渲染用 pending，另用同步 ref 防止同一事件周期重复提交。每次 DOCX 转换拥有 AbortController，Provider 按 key 重建会话时组件卸载会中止转换。大文档定期让出主线程；压缩库不支持中途停止，结束后再次检查取消，旧结果不会弹窗或下载。弹窗关闭释放结果引用；下载沿用现有临时 URL 延迟释放。WebP 转换的 finally 关闭 ImageBitmap 并清空 Canvas 尺寸。

固定依赖 `docx 9.6.1`，只从异步转换模块加载。生产包总计约 2484.3 kB、gzip 753.7 kB；主入口 115.9 kB、gzip 38.9 kB，DOCX SDK 位于 async 分包。本次未更换编辑器、样式体系或状态库。

## 许可与风格审计

新增依赖已加入运行时许可清单。收集脚本改用包子路径取得搜索目录，正确处理 `buffer` 等与 Node 内置模块同名的 npm 包。`hash.js`、两版 `isarray` 的许可从对应官方版本归档；剩余缺失文本仅为原有 `toggle-selection`，没有宣称整个项目分发许可审计完成。

本次新增/修改代码及必要调用链符合 `$qucm-code-style`，确认风格偏差为零。沿用本模块 React 17、AntD 5、双引号、无分号、具名组件、CSS Modules 和显式异步流程；不按技能通用版本建议迁移现有技术栈。`documents` 技能用于测试文件渲染，内容以应用文档契约为准；不将不能转换的公式描述为无损。

原理复核：

1. 为什么动态导入之前捕获 Blob？加载后会话可能已切换，提前固定不可变引用才能使正文、标题与资源属于同一快照。
2. 为什么 pending 之外还需要 ref？React 状态更新可能尚未完成，ref 可同步阻止第二次提交。
3. 为什么不能同时传 rowSpan 并写合并续行？SDK 会自动插入续行，叠加会让网格错位；本实现统一显式输出。
4. 为什么分页使用后续段的段前属性？独立分页符段落可能先挤到新页再执行分页，制造额外空白页。
5. 为什么转换失败保留整个公式？局部跳过节点可能改变数学含义；整式回退保证源码可恢复，并提示排版有损。
6. 为什么压缩结束后再次检查取消？压缩库无法接收 AbortSignal，卸载只能阻止采用旧结果，不能假称强制停止了底层计算。
