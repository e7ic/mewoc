# M6 第四批：公式

## 实施前白盒模型

行内公式和独立公式保存为 `inlineMath` / `blockMath` 原子节点，只有必需的 `latex` 字符串。参照 [Tiptap 公式模型](https://tiptap.dev/docs/editor/extensions/nodes/mathematics)，使用自有轻量节点接入现有白名单与异步渲染；KaTeX 按需加载，不引入官方扩展的同步渲染路径。

- 插入工具栏使用 AntD Modal、Input.TextArea 与 Select；选择已有公式后同一入口变为编辑。编辑时保留原类型，可删除；取消不写正文。不自动转换 `$` 输入，避免意外改写普通文本。
- LaTeX 最多 2000 字符，文档公式源累计最多 100000 字符；schema 校验类型、非空、长度，语法由渲染器检查。导入的语法错误保留源码并显示错误，可重新编辑，不静默丢弃。
- 渲染采用 KaTeX 0.18.7 的 MathML 输出。禁止受信任 HTML/外部资源，maxExpand 200、maxSize 20，每次独立 macros；预览、正文和输出共用选项。语法错误不能通过插入/编辑提交。
- NodeView 保存渲染序号与销毁标记，异步结果只更新当前节点 DOM；渲染失败显示源码与错误，不改变文档。节点更新/销毁使旧结果失效，不引入全局监听。
- 弹窗打开时捕获可映射选区；提交等待渲染验证后再次核对会话、选区、原节点类型及源码。取消/卸载使待提交结果失效；只读和组合输入不提交。
- HTML 序列化携带 data-type/data-latex，导出时预先渲染 MathML；无需外链 CSS、字体或脚本。内部粘贴先收回公式源码，再走白名单，避免把渲染树误当正文。纯文本导出保留带分隔符的 LaTeX。
- 文件协议尚未发布，继续 schemaVersion 1 扩展；旧文件可读，旧程序拒绝新增公式节点。公式源不放到 Zustand；UI 及临时预览只在当前组件拥有。
- 本批适配 Chrome 原生 MathML，其他浏览器和系统打印保留明确验证范围。M5 继续暂缓。

渲染选项依据 [KaTeX 官方选项](https://katex.org/docs/options.html)。

## 风格与契约审计

本次改动及必要调用链确认偏差为零，符合 `$qucm-code-style`，同步执行 `$frontend-code-style` 白盒规则。继续 React 17 / JavaScript / JSX / AntD 5 / Zustand / Rsbuild；用户明确技术栈优先于技能中的通用版本建议。没有 TypeScript、TSX、第二套正文状态或新通用服务层。

具名组件、页面私有 tools/extensions/sass、两空格、双引号、无分号与现有模块一致。公式弹窗沿用选区书签；运行序号属于组件 ref，预览与 loading 属于最近组件；effect 清理取消计时器和迟到状态更新。节点视图没有全局监听，版本校验保护更新与销毁。KaTeX 是本次功能必要依赖，静态导入集中在动态加载模块内。

公式渲染验证是异步过程，提交前重新验证当前文档、可编辑性、组合输入、映射选区、原节点类型/源码；成功命令前后关闭历史合并边界，避免相邻打字被一起撤销。渲染回调只改节点 DOM，不触发自动保存。源码通过 schema 白名单及长度预算，渲染结果只来自受限 KaTeX；错误文本使用 textContent。

## 原理问题与解释

1. 为什么保存 LaTeX 而不保存渲染 HTML？源码是可编辑的语义数据，渲染树属于展示；分离后可更换渲染实现，避免把 MathML 子树误读为正文或扩大文件体积。
2. 为什么不用弹窗打开时的固定位置直接提交？等待渲染期间文档可能变化；书签映射位置后还需核对原公式类型和源码，才能避免改到另一个节点。
3. 为什么关闭弹窗和销毁 NodeView 都要使旧结果失效？动态模块加载不能直接中止，旧 Promise 仍会完成；版本和取消标记让迟到结果不再插入正文或修改旧视图。
4. 为什么 trust=false 之外还限制宏展开并隔离 macros？外部资源权限与计算规模是不同边界；限制展开防止递归消耗，独立宏对象防止一条公式影响下一条。
5. 为什么撤销边界要在操作前后分别关闭？前边界隔开已有打字，后边界隔开接下来的输入；仅关闭一侧仍可能把公式操作与相邻编辑合并。
6. 为什么输出选择 MathML？浏览器原生排版使离线 HTML 不需要外链字体/CSS/脚本；代价是排版取决于浏览器和系统数学字体，需要保留平台验证范围。

## 边界与下一批

本批验证 Chrome 的公式 UI、MathML 与 HTML/打印共用生成链路，未专项复核 Edge/Safari、系统打印窗口或完整辅助技术朗读。超宽公式不自动换行，编辑区可横向滚动，打印可能超出纸张；需用户自行拆分长公式。渲染在主线程、按需加载，尚未宣称大规模公式压力通过。
