# M25 自动分页 · 第四批：长列表与嵌套容器

本批接续[顶层段内分页](m25-paragraph-pagination.md)，将长列表与嵌套流式容器放到同一套屏幕分页流程。原始列表、容器、段落、表格和资源仍由一个 EditorView 持有；自动续页不新建可编辑副本。本批实现与验收结果记录如下；M25 全部能力的持续验收和版本收口仍待后续。

## 范围与边界

无序、有序和任务列表按原项目边界分页，单个项目中的普通长段落可以按真实行延续。嵌套列表保持原层级、项目顺序和缩进；有序列表保留原 `start/type`，任务列表保留原 `checked` 与一份实际勾选控件。

引用、流式文本框和展开详情递归使用其原始可见正文。容器内的普通段落和标题按行分页，内层列表按项目边界分页；嵌套表格可按既有安全行组排版，单元格内部不再次递归切分。正文中的图片、媒体和附件作为原始完整块保留，跨页重排不复制或重建正在播放的节点。

代码块使用原始 newline 行，屏幕续页不在原代码字符串里插入换行；语法高亮继续属于原始代码 DOM。代码页间装饰位于 `pre code` 内，采用合法的块式 span。单行不能安全拆分时保留完整原行，异常长块继续使用超高内容展开布局。

显式 `keepTogether`、RTL、未知视觉布局或其他无法可靠测量的原始块保守回退，不猜测字符断点。超高原子或完整安全组展开一张加高编辑纸面，后续普通内容恢复标准纸高；展开编辑页不能描述为一张物理打印页。

## 原结构与视图装饰

列表边界使用合法的空 `li` 视图装饰，隐藏编号并排除计数增量，避免在 `ul/ol` 下插入错误 div 或让真实项目编号跳号。装饰不属于模型列表项，不新增任务勾选框，也不进入保存与复制。

容器正文边界使用其原始 contentDOM 内的 div 装饰；段内继续使用 span。布局分别以 `listPagination`、`containerPagination`、`paragraphPos/paragraphLine` 与 `codePos/codeLine` 区分断点。页间占位装饰不可编辑、隐藏于辅助技术，仅占当前屏幕的页间留白；裁剪用的节点装饰保留原正文的编辑与辅助技术语义。

布局的 `containers` 记录原始容器的位置、类型和当前未缩放 origin/height。断点稳定后以实际 DOM 矩形记录裁剪位置和高度，不累加 CSS 声明的空隙高度，避免长前缀的小数像素误差。引用、文本框、详情和代码背景通过 `--mewoc-container-clip` 与 `data-mewoc-container-fragment` 按每页正文预算裁剪，避免整块背景和边框涂过页眉页脚及纸间空隙。横向保留边框与选择手柄余量；列表与原项目不裁剪，编号和勾选控件仍能正常显示。

CSS 变量属于 Decoration，关闭或切换分页可随装饰清理。静态 HTML、打印和 Word 不导出容器裁剪变量、背景分片或编辑页间空隙。

## 详情、输入与资源

收起详情只隐藏原 contentDOM，正文 JSON 与资源不删除；隐藏内容不再占当前屏幕分页高度。重新展开后根据实际可见 DOM 重新测量，保留原始详情 NodeView、摘要和内部资源。详情摘要仍是一份真实操作控件，不按页克隆。

Enter 与项首 Backspace 继续使用原列表命令，分别产生真实分项与合并；代码中的 Enter 继续产生真实 newline。输入、删除和分段属于正文历史，自动分页不增加撤销步骤。跨页模型选区、复制和删除只触及原始节点位置。

组合输入期间保留并映射现有装饰，候选结束后测量最终正文。只读保留分页与原任务状态，写入和勾选仍遵循编辑守卫。销毁或切换文档清理测量帧、观察器与相关监听，旧会话页数不能写入新文档。

## 保存与导出

本地保存、历史、模板和 Mewoc 备份仍保留原始嵌套 JSON、编号、checked 和资源。重开按当前浏览器重新测量，不持久化一次屏幕断点，也不把装饰 li 当作模型项目恢复。

HTML 保留原列表、任务、摘要和容器；Word 按既有转换流程独立生成真实正文；TXT 输出原始内容。原始项目与文字只出现一次，自动屏幕断点不会变成硬换行或物理分页符。编辑页数与浏览器打印、Word/WPS 页数可能不同，文件兼容与原生排版以实际导出和原生验收证据为准。

## 浏览器专项

`tests/container-pagination-checks.jsx` 提供完整 Workspace 的 22 项验收，限定在 `127.0.0.1:4190/tests/browser.html` 运行。每例创建独立 `M25-B4 容器验收-时间` 文档，排空保存后卸载并精确清理本轮 ID；保存失败也卸载，不遗留 DOM 或迟到写入。

覆盖 64 原项目无序列表、非 1 起始号及五种有序编号、任务勾选与撤销、单个长项目、多层混合列表、引用/文本框/详情递归结构、详情收起展开、marks/hardBreak/emoji、文本框边框和内边距、UL/OL/task 的 Enter/Backspace、跨页复制删除撤销、嵌套表格与实际播放中的音频、安全回退、手动分页及 200 行 JavaScript、高字号重测、400 项小数精度与纸型缩放、composition 和只读、保存备份重开、HTML/TXT/Word 真实输出，以及开关和旧会话清理。

几何检查遍历原始模型节点，以独立 `DOMRange.getClientRects()` 测量每个可见 grapheme，不调用生产行测量 helper 自证。隐藏详情内容不计入几何；原表格行、媒体、任务勾选框和详情摘要分别验证正文预算。跨页容器的整体矩形不被误当成一条越界正文。

追加两项常见几何专项：前置 400 项小数字号列表后的彩色长文本框，在 75% 与 100% 分别核对原始 DOM 的 origin/height 与布局记录误差小于 1px；代码检查混合空行、仅 newline、尾部换行、CRLF 和空白缩进五种 200 行源码，测量零宽但有实际行高的 Range 以及源码尾光标行，验证原源码与 CRLF 分组不被视图断点改写。

400 项夹具使用产品已支持的 12.75pt，格式重测使用 22.5pt。精度指标记录各续页首字形相对正文页顶偏移的极差，不误称所有字符的最大累计误差。新增专项还验证 400 项前置列表之后的彩色文本框裁剪 origin/height，以及代码空行、尾换行、CRLF 与仅空白源码；最终结果见下方验收记录。
