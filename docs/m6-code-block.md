# M6 第五批：代码块与语法高亮

## 实施前白盒模型

继续 React 17、JS/JSX、Tiptap 3、Zustand、AntD 5、Rsbuild 1 与 Node 18.18+。M5 保持暂缓。复用原 `codeBlock` 的 text* / language 数据模型，替换 StarterKit 中的同名扩展，不创建第二套正文状态或代码编辑器。

- 「插入 → 代码块」将当前纯文字段落转换为代码块。块内直接编辑源码；工具栏 AntD Select 选择纯文本、JavaScript、HTML、CSS、JSON、Bash、Python，提供退出到正文按钮。禁止转换含行内公式/图片的段落，避免静默丢弃节点。
- Tiptap 拥有代码、选区、语言与撤销；高亮是 ProseMirror Decoration，只有显示用途。语言菜单打开时保存可映射选区，只读/切文档时不允许提交。
- 高亮器及六种语法按需加载，不做自动语言猜测。按源码生成 token 文本与类名，使用相同结果构造编辑装饰和导出 HTML；不把用户源码直接作为 HTML 执行。
- 高亮更新延迟 150 ms，编辑器实例拥有计时器、请求序号和装饰。文档变动使旧结果失效，组合输入期间不重排装饰，结束后补算；销毁清理计时器、监听和迟到回调。失败显示纯文本并提示，可继续编辑；导出保留源码。
- 单块超过 20000 字符或文档本轮高亮累计超过 100000 字符时按纯文本显示；容量只约束高亮，不禁止保存源码。未知旧语言保留原属性并按纯文本显示。JSON 仍接受原来 <=1000 字符的语言字段，不破坏既有文件。
- Tab 空光标插入 2 空格，跨行选区按整行缩进；Shift+Tab 删除最多 2 空格或 1 个 Tab。仅同一代码块的 TextSelection 可执行；跨块、组合输入、只读均不改正文。Enter 保留前导缩进，Mod+Enter 或退出按钮继续写正文。修改语言、缩进与退出和相邻打字分别撤销。
- 内部粘贴先取代码纯文本、原语言并丢弃 token 样式，保留空白/换行；外部 HTML 仅保留代码语言白名单属性。VS Code 剪贴板元数据需安全解析；代码块内粘贴始终走纯文本。
- HTML/打印使用内嵌高亮样式，代码块不继承界面深色变量。普通 HTML 与纯文本输出保留源码，打印可折行避免长行横向截断。原格式刷、公式、表格与文档 schema 保持其边界。

设计依据：[Tiptap CodeBlock](https://tiptap.dev/docs/editor/extensions/nodes/code-block)、[CodeBlockLowlight](https://tiptap.dev/docs/editor/extensions/nodes/code-block-lowlight)、[Lowlight](https://github.com/wooorm/lowlight)。实际键盘与剪贴板边界同时审计已安装的 Tiptap 3.31.3 源码。

## 结果

2026-09-08 已完成。在「插入 → 代码块」将当前文字段落转成代码块，使用 AntD Select 选择语言；光标位于代码块时显示语言、退出按钮与键盘提示。直接编辑源码，Tab / Shift+Tab 按整行增减缩进，Enter 继承缩进，⌘ / Ctrl+Enter 或退出按钮进入后续正文。反引号或波浪号围栏加空格也可触发代码块。

语言支持纯文本、JavaScript、HTML、CSS、JSON、Bash、Python。`js` / `jsx`、`xml`、`sh` / `shell`、`py` 等旧属性映射到相应显示语法；不支持的语言保留原属性，并允许显式改为纯文本。高亮只产生 Decoration，不改变代码、选区、文件内容或保存 revision。

动态加载 lowlight 3.3.0 与 highlight.js 11.11.1，只注册六种语法。高亮源码经 HAST token 分解，编辑器生成文字装饰，HTML 输出用 textContent 构造 span；空白、换行和看似脚本的源码不会执行。导出内嵌颜色与打印折行规则；内部粘贴收回纯源码、语言并丢弃装饰。沿用已有 codeBlock / language 模型，没有升级文件 schema 或缩小旧语言字段范围。

## 风格与契约审计

本轮改动及必要调用链确认偏差为零，符合 `$qucm-code-style`，同步执行 `$frontend-code-style` 的白盒规则。用户明确的 React 17 / JS / JSX / Zustand / AntD 5 / Rsbuild / Node 18.18+ 优先于技能的通用版本建议。

## 原理问题与解释

1. 为什么高亮使用 Decoration？语法颜色是显示结果，源码和语言才是文档数据；装饰事务不产生内容 update，避免自动保存和撤销被高亮污染。
2. 为什么动态加载后还要检查文档与请求序号？Promise 返回时用户可能已经修改正文或关闭会话；双重校验只接受当前文档的结果，销毁后不再回写。
3. 为什么 Tab 必须限制在一个代码块内？文本位置并不代表同一语义容器；跨块插入缩进可能吞入后续正文，甚至丢失节点。整行计算还需排除仅触及下一行起点的选区。
4. 为什么代码粘贴单独设置优先级？链接粘贴会把 URL 应用到选中文字；VS Code 的明确源码应先处理。提高整个代码节点的优先级又会改变 schema 的默认块类型，因此只提高粘贴 Extension。
5. 为什么超过高亮预算仍允许保存？预算用于控制显示计算成本，不应变成数据截断规则；较长代码和未知语言保持源码，按纯文本呈现。
6. 为什么导出重新构造 span 而不复制编辑 DOM？编辑 DOM 包含选区和临时装饰；从源码重新生成、用 textContent 写入可保证内容可携带且源码不作为 HTML 执行。
