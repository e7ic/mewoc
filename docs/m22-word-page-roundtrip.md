# M22 · Word 页面设置往返

2026-10-06，验收通过。Word 导入现在恢复受支持的纸型、横竖方向、四边边距与本项目导出的文字水印；预览先展示页面摘要和水印示意，确认后才创建独立文档。

## 使用与范围

选择「导入 Word」，查看页面摘要、正文预览和转换说明，再点击「导入为新文档」。取消、读取中换文件或转换失败不会改变当前会话；确认时仍先保存原稿，保存失败可以保留结果重试。

| 内容 | 行为 |
| --- | --- |
| A3 / A4 / A5 / Letter | 按实际纸面宽高恢复横向或竖向；方向标记冲突时按宽高恢复并提示。 |
| 四边页边距 | Word 整数 twip 转为 0.01 mm；实际往返差异不超过 0.02 mm。恰好 40 mm 正文边界仅在最多 2 twip 的量化误差内微调，并提示。 |
| Mewoc 原生文字水印 | 恢复文字、颜色、不透明度、角度；水印独立于正文，不进入选区、复制或统计。 |
| 普通页眉、页脚 | 延续原语义转换：各份静态内容保留一次，附在正文末尾。 |
| 相同设置的多节 | 保留同一全局页面配置。不同节采用第一节，并提示其余节无法独立排版。 |
| 未知纸型、不适用边距、装订线 | 明确提示回退或未保留；损坏数字、异常位置、重复关键元数据直接拒绝。 |
| 首偶页或分节水印差异 | 仅采用第一节默认页眉的可恢复水印，并提示适用范围变化；只有首偶页或后续节水印时不扩展为全文水印。 |
| 未知 VML / 艺术字 | 继续执行原有严格图形校验，不因类似水印 ID 放行。 |

识别水印同时核对真实页眉关系、有效节、UUID 标识、完整 VML 结构与属性、几何和共享页面契约。完整检查后才从转换用 DOM 移除已识别装饰，源文件字节不变。合法 `sectPrChange` 的旧页眉不属于当前正文，忽略其历史专用部件并提示；当前与历史共用的页眉仍正常处理。缺少页型的旧页眉引用按默认页眉兼容处理，并提示范围不确定。

Word 仍按内容语义转换，字体、字号、颜色、段落间距与原始分页不承诺还原。编辑器仍只有一份全局页面设置，连续纸面只显示一次水印；本批未接入分节编辑、页眉页脚编辑、页码、自动分页或任意第三方水印转换。

## 打印补验与修复

系统 Chrome 154 的实际 PDF 暴露了行内 SVG 水印的绘制问题：两页副本叠在第一页，第二页没有水印；单纯清除纸面定位没有解决。修复后同一水印层在屏幕显示 SVG，在打印显示由同一安全 SVG 编码的 data 图片，两者按媒体规则互斥。正文与分页内容没有复制，也没有增加外部资源。

[逐页核对](m22-word-page-roundtrip-evidence/pdf-checks.json)记录初轮水印次数 `[2, 0]`、修复后 `[1, 1]`，以及 Word 导入后长文的七页 `[1, 1, 1, 1, 1, 1, 1]`。七页均为 A5 横向（594.96 × 420 pt），全部 Poppler 页面渲染已目视检查；实际另存 PDF、浏览器页眉页脚关闭、背景图形关闭。完整输出为[七页 PDF](m22-word-page-roundtrip-evidence/word-roundtrip-print.pdf)，修复前后 PDF 与页面图片均保留在证据目录。

920×600 实际视口补验纸型、方向、边距和水印输入，Tab 可到达取消及应用；Word 导入预览的摘要、正文滚动、Tab 到确认、取消保持原稿与确认后编辑均通过。[导入焦点记录](m22-word-page-roundtrip-evidence/import-narrow-checks.json)、[窄窗口预览](m22-word-page-roundtrip-evidence/import-preview-narrow.png)、[确认焦点](m22-word-page-roundtrip-evidence/import-footer-narrow.png)、[纸张设置焦点](m22-word-page-roundtrip-evidence/settings-narrow.png)可复核。

原生文件代选因浏览器扩展未允许本地文件访问而受阻。交互补验使用开发入口生成真实 DOCX，并仅合成文件输入的 `files/change`，转换、预览、确认、保存和打印均走生产流程；不将其计为原生文件选择器通过。真实界面再次下载的 [DOCX](m22-word-page-roundtrip-evidence/manual-reexport.docx)经正式转换链[重新核对](m22-word-page-roundtrip-evidence/manual-reimport.json)，页面与水印一致，正文没有水印文字。
