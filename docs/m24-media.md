# M24 · 本地音频与视频

## 使用与范围

完整模式与极简模式的「插入」工具栏均有「音频」「视频」。先把光标放在普通文字段落中，再选择本机文件；媒体作为独立正文块插入，显示种类、原文件名、体积、原生播放控件和「下载原文件」。不会自动播放，也不下载或嵌入远端媒体地址。

选中媒体块后可下载原文件或删除音频/视频；删除只移除正文引用，撤销可恢复原播放器与原字节。只读预览仍可播放和下载，插入与删除禁用。正文文字编辑和选区变化不重建正在播放的控件；同一资源的多个播放器各自保持播放状态。删除节点、关闭历史预览或离开文档时，旧播放器暂停并移除播放地址。

| 种类 | 文件格式 | 持久化 MIME |
| --- | --- | --- |
| 音频 | MP3 | `audio/mpeg` |
| 音频 | WAV | `audio/wav` |
| 视频 | MP4 | `video/mp4` |
| 视频 | WebM | `video/webm` |

单个音视频文件必须大于 0 且不超过 **5 MiB**；正文当前引用的图片、附件和音视频合计不超过 **20 MiB**，相同资源 ID 重复引用只计一次。最终 Mewoc 便携文件仍受 **32 MiB** 限制：原字节转为 base64 与正文 JSON 后，最终 UTF-8 文件超限也会拒绝导出，不生成无法回读的备份。

文件名、种类、MIME、实际字节长度和容器头均须通过验证。文件选择入口可把已知 WAV/MP3 MIME 别名归一化为表中 MIME；操作系统未提供 MIME 时，仅按受控扩展名确定候选类型，随后仍核对真实容器及原生读取。冲突的 MIME 声明不会按扩展名强行接受。

播放支持还取决于容器内的编码和当前浏览器，扩展名或 MIME 本身不能保证所有文件可播放。产品检查原生 `canPlayType()`，再等待 `loadedmetadata`，校验有效时长和视频画面尺寸，错误或超过 10 秒时明确拒绝；本地有限 WebM 若报告 Infinity 未知时长，不伪造总时长。MDN 分别说明了 [canPlayType 的能力判断](https://developer.mozilla.org/en-US/docs/Web/API/HTMLMediaElement/canPlayType)、[loadedmetadata 的元数据事件](https://developer.mozilla.org/en-US/docs/Web/API/HTMLMediaElement/loadedmetadata_event)及[容器、编码与媒体格式的区别](https://developer.mozilla.org/en-US/docs/Web/Media/Guides/Formats)。

## 保存、历史与异步交互

正文仅保存 `media` 节点及 `assetId`；文件名、类型、原始 Blob 与运行时 URL 由资源集合持有。插入保留原文件字节，不转码；URL 不写入 Mewoc 文件或数据库。资源与正文通过现有原子保存流程写入，读取后建立当前会话地址。

保存重开、文档副本、Mewoc 文件、历史版本和模板均保留媒体种类、MIME、文件名、稳定内部引用及原字节。副本、历史与模板拥有独立持久资源，不依赖来源文档的当前 Blob；来源删除或清理不破坏独立实例。未被正文引用、仅为当前会话撤销保留的资源，不计入正文容量，也不进入导出文件。

媒体插入与相邻文字输入分别占一次正文撤销；删除也可单独撤销/重做。成功资源的 Blob 与 URL 留在当前会话中支持撤销，不因正文暂时删除引用而立即回收。

打开原生文件选择器前捕获原文字选区书签。文件返回与原生媒体读取期间，书签跟随主事务及追加事务完整映射，不改用用户后来移动的光标。只读、切换、组合输入、原目标删除、会话结束或取消信号一旦发生，该目标永久失效；即使随后恢复编辑或重插相同段落，旧任务也不会复活。图片、附件和媒体共享同步任务锁，阻止并发接纳资源。

读取前按文件大小预检额度，读取完成后按最新正文引用再检查。失败、取消、超时或尚未被正文接纳的迟到资源解除订阅并释放临时 URL；成功登记后由文档会话统一管理，卸载时回收。

内部复制只恢复当前已存在且种类匹配的媒体资源。外部粘贴的播放器、远端地址和伪造资源引用不会创建本地音视频节点，原有可读文字可保留。

## 输出行为

| 格式 | 音视频处理 |
| --- | --- |
| Mewoc | 保留完整原字节和内部引用，导入后可继续播放、下载和编辑。 |
| HTML | 内嵌原格式数据，保留原生播放器、原文件下载及文件说明；无需远端媒体地址，仍依赖浏览器编码支持。 |
| Word / DOCX | 按正文顺序保留种类、文件名和体积说明；不嵌入播放内容，导出结果明确提示降级。 |
| Markdown | 保留可读文件说明并提示降级，不生成伪造媒体链接。 |
| TXT | 保留可读文件说明并提示降级。 |
| 打印 / PDF | 隐藏播放器、进度控件与下载按钮，保留文件说明及纸面无法播放的提示；打印入口说明完整资源应使用 Mewoc 或 HTML。 |

源文档和资源不会因降级导出而被修改。本批不含在线媒体、链接抓取、转码、剪辑、录音入口、字幕、自动播放或嵌入式 Word 播放对象。
