# M25 自动分页 · 第二批：跨页表格与重复表头

本批在[第一批多页编辑视图](m25-pagination.md)上接入表格行组跨页与重复表头。正文仍由一个编辑器拥有，原表格、原始单元格和资源节点保持一份；页间空隙与续页表头只属于当前屏幕布局。M25 尚未全部收口，后续已接入[段内分页](m25-paragraph-pagination.md)和[长列表及嵌套容器分页](m25-container-pagination.md)，持续验收留待最终收口。

## 使用与范围

表格随当前纸型、方向、四边边距和实际列宽自动分页，无需另开分页选项。正文输入、字号与行距、单元格内边距、最小行高、图片加载和列宽变化都会重新测量。续页继续使用原单元格，可编辑文字、增删行列、合并拆分、选格、复制、清空和撤销。

每张编辑纸面继续独立显示水印、页眉、页脚与实际编辑页码。50%–150% 缩放与适应宽度只改变显示比例，分页使用未缩放的实际尺寸。表格结束后的普通段落按同一自然流坐标继续排版，不另建编辑器或插入持久空白段落。

内层表格随所在外层完整行组排版，本批不再对嵌套表格单独插入跨页断点。异常网格不能作为逐行分页依据时，保留整表内容并使用完整展开布局，不猜测或静默改写合并结构。

## 安全行组与表头规则

- 普通行在行边界换页。纵向合并格覆盖的行、重叠跨度和连锁跨度合并为一个完整行组，分页空隙不能插入组内。横向合并格保持原 `colspan`，间隙跨越表格的真实逻辑列数。
- 可重复表头仅来自表格起始处连续、全部为表头格且各格没有纵向合并的原始行。无表头、混合普通格、纵向合并头和表格中部的表头行不自动转为重复表头。
- 原始连续表头与首个数据行尽量同页；整个链放不进标准正文区时退回逐组布局，避免持续产生空页。表格首行整体换页时空隙位于整表之前，不复制尚在正文中的原始表头。
- 表内续页只有在重复表头与当前完整行组、必要段距能共同装入标准正文区时显示重复头。无法容纳时只省略该页的重复头，原始头和全部真实数据行仍保留。

超过标准正文高度的单行或完整合并行组独占一张加高编辑纸面，标为「超高内容页」。该页不再添加挤压正文的重复表头；后续普通行组恢复标准纸高。展开页保留全部正文、格边框及上下边距，不表示一张物理打印页。

## 视图与数据模型

原表格继续使用既有 `table / tableRow / tableCell / tableHeader` schema，正文没有新增分页节点或重复行，schemaVersion 不变。IndexedDB、Mewoc 备份、历史、模板、字符统计和正文复制仍只读取原始文档。页数与布局存放在当前会话视图状态，布局事务不增加保存修订或正文撤销步骤。

结构分析器依据原始 `TableMap` 提取逻辑列数、安全行组和连续表头。测量器读取原行 DOM 的自然起点、完整行组高与首尾空白，再扣除已存在的分页间隙和重复头；规划器据此安排页面。每次换页校准浏览器实际实现的小数高度，避免把 CSS 声明值当作累计 used-pixel。

顶层换页使用普通 `Decoration.widget`。表内换页使用不可编辑的跨列 `tr` 间隙和静态重复头装饰；两者共同占用计划的装饰高度，不进入导出快照。原始 TableView、图片与播放器不因仅视图重排被复制或重建。

增删行或改变合并跨度时先撤掉旧表内装饰，再按新网格测量。这样旧虚拟 `tr` 不会进入新 `rowspan` 的覆盖范围。前方文字变化后，断点随正文位置映射，重复头从当前表格读取，不沿用旧绝对位置。

## 富表头静态净化与交互

重复头保留原文字、单元格外观、列宽、横向合并和静态内容。详情节点的标题转为静态展示；媒体显示文件说明，不复制原生播放控件。净化后保持原行实测高度，避免删掉控件后重复头下沉或正文位置漂移。

重复头去掉导航 ID、书签身份、活动链接地址、焦点与选格样式，以及输入控件、下载操作和图片编辑手柄。装饰隐藏于辅助技术，不能成为第二份可编辑正文或导航目标。列宽拖动只接受真实格边，虚拟间隙与重复头不参与拖动或模型选格。

跨页 CellSelection 与复制继续以原模型位置为准；选格、清空及撤销不包含重复头和页间空隙。组合输入期间保留已有装饰，候选确认后测量最终正文。合成 composition 和鼠标事件只验证自动化控制流，不能替代真实输入法候选或物理按住鼠标的手动验收。

只读保留相同分页与静态重复头，写操作仍遵循会话权限。关闭或切换文档清理测量帧、定时器、尺寸观察与相关监听，旧布局不能写入新会话。

## 保存与导出

Mewoc、本地保存、历史和模板只保留原始行与资源。重新打开后按当前浏览器实际尺寸重建屏幕分页，不保存某次测量得到的断点，也不把虚拟头作为用户内容恢复。

HTML、浏览器打印和 Word 从固定快照独立排版，不使用编辑 DOM 中的空隙与重复头。HTML 的静态表头结构和 Word 的原生表头规则继续按原始表格输出；真实内容只输出一次。编辑页数、系统打印页数与 Word 页数可能不同，不能把屏幕断点描述为原 DOCX 布局还原。

## 实现入口

- `tools/table-pagination.js`：只读分析逻辑网格、纵向合并行组和起始连续表头。
- `tools/page-pagination.js`：表格边界、续页表头预算、展开行组及小数校准。
- `extensions/page-pagination.js`：实测原始行、虚拟间隙与净化重复头、结构变化清理和会话生命周期。
- `sass/page-pagination.scss`：仅屏幕分页视图的表内间隙、无边框留白与非交互重复头。
- `extensions/table-column-resize.js`：拒绝虚拟格边，只从真实格测量并提交列宽。
- `tools/html-export.js` 与 `sass/content.scss`：把连续真实表头移到静态 `thead`，仅在打印样式中启用表头组重复。
