# M25 自动分页 · 第一批

本批把编辑区从连续白纸容器改为按正文块实测的多页视图。段落、标题、图片、媒体及其他顶层内容在块边界自动换页，保留一个编辑器和一份文档。第一批完成时，段内按行分页、跨页表格和重复表头尚未接入；下文保留当时范围与验收。

后续：[第二批跨页表格与重复表头](m25-table-pagination.md)已接入安全行组分页、原始连续表头的静态重复、合并格与跨页编辑保护；[第三批](m25-paragraph-pagination.md)接入顶层普通段落与标题按行跨页。长列表与嵌套容器分页仍待后续批次。

## 已接入

- 根据纸型、方向、边距、正文宽度和实际 DOM 高度分页；正文输入、删除、格式变化、字体加载与资源加载会重新测量。
- 各页独立绘制白纸、水印、页眉和页脚，编辑页码显示实际 `n / N`；底栏显示编辑视图页数。
- 手动分页符优先，首尾及连续分页符保留空页；可删除和撤销。
- 标题默认与下段同页，显式段落设置优先；放不下一页的同页链退回逐块布局。
- 50%–150% 缩放与适应宽度只改变显示比例，不改变分页位置。
- 超过标准正文高度的单个段落、列表、表格或容器独占加高纸面，标为「超高内容页」，保留全部内容和上下边距；后续普通内容恢复标准纸高。

## 数据与交互

自动页面间隙是 ProseMirror `Decoration.widget`，不增加正文节点，不改 schemaVersion，也不写入 JSON、IndexedDB、历史、模板、Mewoc 备份或正文撤销记录。文字、批注、查找与跨页选择继续使用原始文档位置；复制不带纸面装饰。

布局事务不增加保存修订。组合输入期间映射已有装饰，确认候选后再测量；真实输入法仍须独立手动验收，合成 composition 测试不能替代候选操作。会话卸载清理 RAF、定时器、尺寸观察、字体及资源监听。

每张超高内容页是编辑视图的展开纸面，并非一张物理打印页。状态栏区分正常页数与展开纸面数量。HTML、浏览器打印和 Word 始终从快照重新排版，不承诺与屏幕分页位置一致；历史、模板和页面设置的小型预览保留 `第 1 / … 页` 示意。

## 实现入口

- `tools/page-pagination.js`：纯几何规划、同页链、手动空页和超高块退化。
- `extensions/page-pagination.js`：真实块测量、仅视图事务和事件清理；默认禁用，由纸面组件启用。
- `hooks/use-page-pagination.js`：页面设置与当前会话布局同步。
- `components/PaperCanvas.jsx`：单一正文层与独立多张纸面。
- `sass/page-pagination.scss`：仅屏幕编辑器的块布局与间隙样式，不进入静态 HTML 的正文样式。

## 验收

2026-10-06 第一批验收完成：Node 全量 **711/711**，Chrome 浏览器 **143/143**（自动分页 15、纸张设置 11、页眉页脚 10、基础编辑 62、工具栏 29、媒体 11、Word 导出 5）；全量 lint、生产构建及 `git diff --check` 通过。

400 段小数字号与段间距长文生成 14 页，最大累计位置偏差 **0.01055 px**。覆盖纸型/方向/不对称边距、50%–150% 缩放、字体与图片加载、媒体播放、手动空页、同页链、超高内容、跨页选择/复制/退格/撤销、查找、只读、组合输入保护及保存重开。页眉页脚在每张编辑纸面显示真实页码。

另完成 Chrome 原生单次粘贴：页尾段落由第 1 页移到第 2 页，重排后光标仍在可见编辑区域；这项证据不代表真实输入法候选验收。正式 4177 页面重新打开正常，控制台错误为空。开发期间发生的 HMR 中断与测试端口门禁误拒绝已修正，最终数字只统计完整通过的重跑结果。静态 HTML 和 Word 导出回归通过，本批未新增系统打印或 Word/WPS 原生排版验收。

新增入口为专用测试端口 `/tests/browser.html` 中「运行自动分页验收」。所有测试数据限定为本轮创建的专用记录，正式 4177 端口中的用户文档不参与清理。详见[验收汇总](m25-pagination-evidence/verification-summary.json)、[原生光标证据](m25-pagination-evidence/native-caret.json)和[分页截图](m25-pagination-evidence/editor-pagination.png)。
