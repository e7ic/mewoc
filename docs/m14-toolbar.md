# M14 · 工具栏与上下文交互

日期：2026-10-02。依据用户提供的开始/表格工具栏截图，并实际操作 [Umo 在线演示](https://www.umodoc.com/demo)，在现有编辑器中调整布局和交互。未引入 Umo 依赖或复制其实现。

## 本轮范围

工具栏分为「开始、插入、表格、工具、页面、视图、导出」。保存状态放在标签栏右侧，继续准确区分未保存、正在保存、本浏览器已保存和失败；文件管理与标题保留在上方。

开始采用历史/字体/段落的紧凑双行分组与末尾样式卡片。字号增减使用原有字号白名单；格式刷的连续模式、应用和取消放入选项弹层；首行和左侧缩进放入段落缩进弹层，原精细设置入口保留。单行模式保留各标签和全部操作，通过横向滚动访问溢出工具。

各标签面板持续挂载，切换标签保留设置草稿、原选区书签、导出异步任务和确认结果；临时菜单随隐藏或切换布局关闭。标签支持左右箭头、Home/End；鼠标切标签不清空正文选区。横向箭头使用真实滚动，边界状态由实际容器尺寸测量，卸载时清理 observer 和 RAF。

表格进入时自动切换上下文工具；手动切回开始后仍可设置单元格文字。离开表格恢复开始。表格增加上/下插行、左/右插列、表头行/列/单元格、前后单元格导航，以及 12 种组合对齐和单元格底色快捷面板。组合对齐在单个事务写入选中单元格的垂直对齐及内部段落的水平对齐，可一次撤销；跳过内嵌表格。删除确认保留打开时的表格目标，避免后来改选区时删错表。

## 参考观察

在真实演示页点击浏览器支持表格的 Google Chrome 单元格，工具栏自动进入表格；单格状态下合并和拆分禁用。打开对齐方式可见 3 种垂直 × 4 种水平组合，选择「中间居中对齐」后原单元格的 computed vertical-align=middle、段落 text-align=center。点击表格外标题恢复开始。

演示的「切换工具栏」菜单提供专业、经典和隐藏模式；经典模式把操作压为单行、标签改为下拉。本轮保留 Mewoc 七个可访问标签，以直接切换单双行提供相同的节省高度用途。没有新增隐藏工具栏模式。

证据保存在 [m14-toolbar-evidence](m14-toolbar-evidence/)。对照开始截图时将 2288×270 源图按 2× 密度归一为 1144×135；本地 CSS 视口为 1144×800，工具栏单独截取。源图的未保存状态、默认字体字号与实际文档状态可能不同，不能用占位文案覆盖真实回显。源图尚未支持的功能不添加无效按钮。

## 验证

Node 24.13.1 全量 **394/394**，lint 零警告与生产构建通过。工具栏新增浏览器专项 **11/11**，既有段落 **9/9**、样式交互 **9/9**、图表精细设置 **10/10**、常规编辑 **62/62**、批注 **8/8**、文档库 **8/8**、历史 **11/11**、Word 导出 **5/5**、Word 导入 **6/6**、模板 **10/10** 通过，共 **149/149**。

新增表格属性组合测试暴露旧书签算法以 cell 内容起点映射的缺陷：首段/首行合法属性变更会被误判原目标已删除。本轮改为逐 step 校验表格/单元格自身开始 token，允许保留内容的节点属性变更和 cell/header 切换；整表或原单元格同位置替换仍使旧目标永久失效。追加事务必须保持完整链。独立审查另补验嵌套表格祖先属性变化和替换，结果通过。

初轮验收调整了旧测试的纯文本按钮定位、格式刷弹层入口和自动表格标签预期；窄宽滚动使用 1px 容差等待真实边界。书签专项的前方插入明确使用 updateSelection:false，模拟不离开表格的外部内容更新；主动离开表格会关闭临时浮层，属于预期行为。开发期 HMR 重置的运行不计入结果。模板测试读取全库新增数量，不能与创建文档的其他套件并行，最终单独执行。
