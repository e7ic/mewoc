# M9 · 本地批注

日期：2026-10-01。当前在「工具」中选中文字添加批注，右侧面板支持定位、编辑、解决、重新打开和删除。它是当前文档的单人本地审阅功能，不引入账号、多人回复或修订模式。

2026-10-02 M14 入口迁移：「审阅 → 添加批注」改为「工具 → 添加批注」，批注面板开关也位于「工具」。下方验证成绩和证据保留 2026-10-01 批次记录。

## 使用与保存

选择正文、标题、列表或表格单元格中的文字，打开「工具 → 添加批注」，输入意见并保存。选区可以跨段落；每个文字范围只关联一条批注，已有批注覆盖的选区不能再次添加。代码块、图片、公式、附件和硬换行不能进入选区。每份文档最多 200 条批注，每条最多 2000 个字符，创建时原文摘录最多 500 个字符。

批注面板显示当前关联文字、意见和状态，可筛选全部、待处理与已解决批注。点击正文高亮会打开面板，点击面板引用可定位到正文。原文编辑后定位随文字标记变化；全部引用被删除时，意见保留并显示「原文已删除 · 无法定位」，撤销正文删除后可重新定位。

新增、编辑、解决、重新打开和删除批注均进入正文撤销历史。批注修改与前后的普通输入分开撤销。只读模式可以查看、筛选和定位，禁止修改；只读切换时，已经打开的表单保留草稿并禁止提交。弹窗书签随正文事务映射，原选区删除后不会把批注写到另一段文字。

## 文档与文件

批注线程位于正文根节点 `attrs.commentThreads`，文字锚点使用 `commentAnchor` 标记和稳定 ID。元信息与锚点在同一个正文事务内写入，由现有保存队列、IndexedDB、文档复制和历史检查点共同保留。无批注的旧文档仍可读取，不升级本地数据库、不增加运行依赖。

清除文字格式保留批注定位，格式刷既不复制来源批注，也不移除目标批注。普通复制粘贴保留正文与文字格式，移除批注 ID，避免重复或跨文档引用。HTML 解析不接纳批注标记。

同一编辑器中拖动移动正文会保留批注定位；拖动复制只复制文字与格式，原批注留在来源位置。移动或复制按释放时的实际操作判断，拖动途中改变修饰键不会错误复用批注 ID。

Mewoc 文件保留可继续编辑的批注内容、状态和定位。HTML 与打印、Word、Markdown、纯文本追加「批注说明」，保留创建时引用、当前引用、意见、时间与状态。Word 和 Markdown 导出提示原生批注定位与交互不保留；这批没有实现 Word 原生批注导入或导出。历史版本只读预览也展示旧版本批注说明。

外部文档的线程数量、字段、ID、字符串、日期及状态均严格校验；无对应线程的正文锚点拒绝进入保存，失去正文锚点的线程允许保留。批注随本地文档保存在当前浏览器，清除站点数据会一并删除，重要文档仍应导出 Mewoc 文件备份。

## 验证

Node 24.13.1 全量测试 262/262、lint（零警告）、生产构建与 `git diff --check` 通过。新增 33 项测试：核心模型与命令 16 项、拖动事件 7 项、格式/剪贴板/文件往返集成 5 项、导出 5 项。

内置浏览器批注专项 8/8、常规编辑回归 62/62、历史版本 11/11、文档库 8/8、Word 导入 6/6。专项使用真实 Provider、工具栏、弹窗、纸张、保存队列与 IndexedDB，覆盖跨段创建、编辑解决筛选删除撤销、锚点插删映射、只读草稿保护、保存及同 ID 会话重建、历史恢复前备份、剪贴板与格式保护、书签失效后保留输入。每轮只清理本次随机 fixture ID，不清空数据库或删除既有用户文档。

审查发现原剪贴板处理会在同编辑器拖动移动时剥离锚点，已保留原生移动事务，只对最终判断为复制的拖动剥离新副本锚点。7 项拖动回归走实际 ProseMirror 原生事件处理链，包含中途改变修饰键、跨编辑器拖入、节点复制和只读/切换/输入法组合期间禁止写入；JSDOM 坐标使用测试替身，不将它作为物理鼠标补验。首轮浏览器检查还发现旧编辑器延迟销毁的断言时序问题，等待实际销毁后，新实例与撤销历史隔离检查通过，产品未因此改动。

完整页面使用本批新建「本地批注 · 演示」验证键盘选区、添加意见、侧栏高亮、手动保存与刷新后恢复。另保存「含批注的检查点」，确认历史只读预览显示原始引用、当前引用、批注内容、时间与状态。没有编辑 4177 端口上的用户文档。本批没有重做 Safari 物理鼠标、Chrome 真实输入法或 Node 18 验收。
