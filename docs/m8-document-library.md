# M8 · 文档库管理

日期：2026-10-01。顶部「最近」扩展为「文档库」，提供标题搜索、排序、分页、重命名、复制、回收站及恢复。沿用现有编辑器、保存队列和 IndexedDB；不新增运行依赖、数据库版本或便携文档版本。

## 功能与用法

- 点击顶部「文档库」，先提交当前会话尚未保存的正文和标题，保存成功后读取本浏览器文档。列表标记当前文档，显示创建时间与更新时间。
- 搜索按标题字面匹配，不区分字母大小写。支持按更新时间、创建时间或标题排序，每页 6 份；回收站还支持按回收时间排序。搜索、排序和翻页使用已读取的列表，切换分类、刷新及管理成功后重新读取仓库。
- 「重命名」去除标题首尾空白，要求 1–100 个字符。当前文档继续使用同一编辑器与保存队列，保留正文选区和撤销历史；标题变更不替换正文，也不重建会话。其他文档通过仓库事务更新标题。
- 「复制」生成新 ID 和独立记录，标题添加「 - 副本」，必要时截短原标题以保留后缀，总长不超过 100 个字符。副本包含最新保存快照的正文、纸张设置以及引用的图片和附件原始字节，来源记录与当前会话保持不变；副本可随后从列表打开。
- 「移入回收站」需要确认。回收当前文档时先保存，再提交回收事务；成功后切到新空白文档，旧会话随卸载结束。回收其他文档不切换当前会话。
- 回收站仅显示已回收记录。「恢复」移除回收标记并更新文档时间，恢复后的记录回到文档分类。图片和附件一同保留；本批没有永久删除或清空回收站入口。
- 打开文档时，当前会话先保存，再重新读取目标的最新活跃记录与资源。列表中的旧快照不能直接覆盖目标；已被其他标签页回收的目标会明确报错。

实现入口：[LocalDocumentsAction.jsx](../src/pages/editor/components/LocalDocumentsAction.jsx)、[FileActions.jsx](../src/pages/editor/components/FileActions.jsx)、[library.module.scss](../src/pages/editor/sass/library.module.scss)。

## 持久化与版本保护

持久记录在原有 `{ id, document, storageVersion }` 顶层增加 `deletedAt`，正文的 `schemaVersion: 1` 不变。没有回收字段的旧记录仍按活跃文档读取；缺省存储版本按 0 解释。IndexedDB 保持 `mewoc` v1，继续使用 `documents` 和 `assets` 两个仓库，无需迁移已有文档。

重命名、回收、恢复在同一个读写事务中读取当前记录、检查基础版本、更新记录并递增 `storageVersion`。过期请求返回 `DOCUMENT_CONFLICT`，不覆盖其他标签页的内容。当前重命名经同一保存协调器提交，新版本继续由协调器持有，随后自动保存不会使用旧版本。

复制在同时覆盖文档与资源仓库的事务内检查来源版本，新记录版本从 1 开始，来源版本不变。资源 ID 保持稳定，数据库键按 `${documentId}:${assetId}` 隔离；对副本删除图片或附件不会删除来源资源。任一资源缺失、类型/长度不符或写入失败都会中止整笔复制，回滚已排队的新记录与资源。

回收只增加持久标记并更新版本，不删除资源。普通保存即使携带回收记录的最新版本，也返回 `DOCUMENT_TRASHED`；过期版本仍返回冲突。旧会话的迟到保存不能自动复活回收记录，必须通过明确的恢复操作移除标记。

实现：[local-repository.js](../src/pages/editor/tools/local-repository.js)、[use-document-save.js](../src/pages/editor/hooks/use-document-save.js)、[save-coordinator.js](../src/pages/editor/tools/save-coordinator.js)。

## 失败重试与异步收口

- 准备文档库或切换文档时，保存失败保留当前会话；页面恢复原有编辑状态，显示错误并提供重试。未成功保存的编辑仍可通过现有导出流程备份。
- 管理操作使用同步互斥标记，防止快速重复点击；保存、文件读取和会话切换共享互斥。准备与管理期间禁止关闭弹窗，完成后恢复操作。
- 读取失败可重试；过期列表导致重命名、复制、回收或恢复失败时，不静默替换基础版本。应取消确认弹窗、刷新文档库后再操作；当前会话发生版本冲突时，先导出未保存副本，再刷新读取最新记录。
- 当前文档若在其他窗口被回收而仍有未保存修改，直接恢复会被拦截，避免丢弃本会话正文。保留导出入口供用户备份，再重新读取并恢复仓库版本。
- 关闭、切换分类、刷新及卸载使当前读取失效，迟到的列表结果不会写入下一次弹窗。会话卸载后，保存队列停止调度与状态回报；已交给 IndexedDB 的事务可能完成，仍受版本与回收状态校验保护。
- 目标资源读取完成且组件仍挂载后才创建临时 URL；提交失败时释放新建 URL，会话资源按既有卸载流程统一释放。

## 限制与后续

- 文档库仅属于当前浏览器及站点来源；不提供账号、云同步、跨浏览器共享或实时跨标签页列表推送。其他标签页变更后可手动刷新，写操作仍检查持久版本。
- 回收站仍使用同一份浏览器本地存储，不是备份。清除站点数据或浏览器存储失效会同时影响活跃文档和回收文档；重要内容继续使用现有导出文件备份。
- 回收站不会按时间自动清空，也没有永久删除入口；图片和附件继续占用本地容量。复制会增加独立资源占用，配额不足时明确失败并回滚。
- 此批不保存历史版本或提供旧快照恢复；正文撤销仍属于当前编辑会话，重新打开文档会重建撤销历史。

后续批次已在本次持久记录与版本保护之上实现[历史版本](m8-document-history.md)：检查点连同引用资源保留，并提供预览、恢复及另存副本流程。上文验收数字保留为文档库批次记录。
