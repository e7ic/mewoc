# M17 · 编号、上下标与待办清单

日期：2026-10-03。本批补齐「开始」分组的三项基础编辑能力，完整模式和极简模式共用入口、状态及命令。

## 交互

- **编号设置**：有序列表按钮旁的下拉支持数字、小写/大写字母、小写/大写罗马数字；起始号接受 1–999999999 的整数。仅当前同一层有序列表可打开。面板固定打开时的原列表及光标，正文前方变化会映射目标；删除、替换或跨列表选区不能误写其他列表。应用两个字段仅产生一次撤销，取消不修改正文。
- **上标与下标**：两种格式互斥，支持文字选区及随后输入；保持兼容的其他文字格式，格式刷和清除文字格式同步支持。行内代码、代码块等不接受这些标记的内容不会被强行改写。
- **待办清单**：正文可转为可勾选清单，支持嵌套、增加/减少缩进及三种列表互转。勾选与创建清单分别撤销。Enter 新建事项默认未完成，空事项可退出列表。普通列表转换为任务时直属项默认未完成，已存在子列表保持原类型和完成状态。

工具栏按最近列表层回显，嵌套普通列表不继承外层待办的按钮状态。跨已有列表与外部段落的混合选区暂不转换，对应入口禁用，避免展平多段项目及嵌套内容。完整单列表全选与普通多段正文支持转换。

只读、文档切换和组合输入期间不执行新写入；正文复选框随只读状态禁用及恢复。编号浮层随模式、分组或禁写状态变化关闭；Esc 关闭并回到入口。面板保留滚动和焦点描边留白。

## 保存与文件格式

新增任务节点和上下标 marks 接入文档校验、自动保存、历史/模板、Mewoc 备份以及实际剪贴板清理。剪贴板只保留合法任务标记、布尔勾选状态、编号属性及允许的上下标样式，剥除外部表单元素。

| 格式 | 编号 | 上下标 | 待办 |
| --- | --- | --- | --- |
| Mewoc 文件 | 保留样式与起始号 | 保留 | 保留可编辑层级及状态 |
| HTML / 打印 | 原生列表属性 | 原生 sup/sub | 静态禁用复选框，保留状态 |
| Markdown | 保留数字起始号，字母/罗马样式有降级说明 | 保留文字，提示丢失上下标格式 | GFM 的 `[x]` / `[ ]`，支持嵌套与混排 |
| Word（DOCX） | Word 编号定义 | 原生 vertAlign，导入可恢复 | 静态 `[x]` / `[ ]`，明确提示不生成 Word 可交互任务控件 |
| 纯文本 | 沿用正文文本输出 | 保留文字 | 保留 `[x]` / `[ ]` 状态前缀 |

空待办导出 Markdown 时补「（空待办）」并提示，避免空列表项无法保留状态。Word 静态待办重新导入后不会自动转回可交互清单。Markdown 导入仍不执行内嵌 HTML。
