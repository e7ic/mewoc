# Tabler 图标统一

2026-10-02，按用户要求将应用直接使用的图标统一为 Tabler Outline。

## 实现

- 固定 `@tabler/icons-react` 3.48.0；组件按名称静态导入，保留构建 tree shaking。该版本声明支持 React >= 16，兼容当前 React 17。
- 移除 `@ant-design/icons` 直接依赖，应用源码不再导入旧库，也不使用旧命名的图标别名。AntD 5 本身仍依赖旧库，因此锁文件和第三方许可清单保留真实的间接依赖，未修改或伪造其依赖声明。
- 覆盖工具栏、插入、表格设置、导出、文件操作、文档库、历史版本、模板、批注、查找、大纲、公式与状态栏。通过公开组件属性替换下拉箭头、关闭按钮、分页按钮、数值输入按钮、消息/警告及加载图标。
- Tabler 默认 stroke=2；主要工具栏、文件操作和表格操作 20px，辅助图标及下拉箭头至少 18px，插入/导出入口 24px。数字输入步进按钮受半行高度限制，独立使用 14px。保留原按钮的中文文字、title、aria-label、禁用与选中行为，装饰 SVG 使用 aria-hidden。
- 引用使用 `IconBlockquote`，缩进使用 `IconIndentIncrease/Decrease`，分页符使用 `IconPageBreak`，表头行/列分别使用 `IconTableRow/Column`，字号增减使用 `IconTextIncrease/Decrease`。当前 Tabler 无专用单元格合并/拆分图标，使用 `IconArrowsJoin2/Split2` 并保留明确按钮文字。
- 加载旋转图标遵循减少动画偏好；实际加载文案、Spin 的状态语义及按钮防重复点击保持。
- 颜色面板通过 ColorPicker 的公开 panelRender 定制，使用已经由 AntD 引用的 `@rc-component/color-picker` 2.0.1 调色基础组件；将该版本声明为直接依赖以避免访问未声明的传递依赖。自有 HEX/RGB/HSB 数值输入和色相滑块保持原功能，原 AntD 图标面板不渲染。

## 验证

Node **397/397**、浏览器 **102/102**（基础 62、工具栏 11、文档库 8、历史 11、模板 10），lint、生产构建与 `git diff --check` 通过。构建总计约 3264.5 kB / gzip 962.6 kB。颜色输入另有实际 UI 补验：HEX 红色、RGB 绿色、HSB 黑色状态保留色相再恢复蓝色、无效草稿、色相方向键、默认高亮应用和撤销、切标签收起弹层均通过。

主服务 `http://127.0.0.1:4177/` 已重启清除旧开发构建缓存，重新加载后编辑器正常显示。应用主页以及 HEX/RGB/HSB 颜色面板均核对无可见 `.anticon` 元素。

结果和界面截图保存于 [tabler-icons-evidence](tabler-icons-evidence/)。本轮只针对图标迁移及必要的颜色面板组合进行回归，不重做原生输入法、鼠标拖动或 Word/WPS 验收。

迁移时发现分页自定义图标需要保留原按钮结构，已恢复按钮、边界 disabled、中文 aria-label 和原键盘路径。附件测试的消息捕获改为读取带图标参数中的 content，原错误信息断言保持。

## 图标尺寸补齐（2026-10-02）

用户反馈文件操作、底部大纲、切换工具栏和下拉箭头过小。实测原图标随文字缩至 8–13px；现通过 `max(1em, 18px)` 提供统一下限，避免批注、弹窗、搜索等辅助区域遗漏，同时保留 24/28/48px 大图标。底部图标为 20px、点击区域为 28px，侧栏关闭按钮为 18px、点击区域为 26px。

Select 使用公开 `fontSizeIcon` token 同步调整箭头占位与居中。格式刷箭头、样式展开列、字号与行距选择框同步加宽；颜色面板扩大至 280px，使三位 HSB 数值与步进按钮同时可见。数字步进箭头虽占 14px SVG 画布，实际线条完整显示在半行按钮内。窄屏文件操作栏略缩组间距，工具栏继续使用原生横向滚动。

本次尺寸调整验证：工具栏浏览器回归 **11/11**；lint、生产构建、`git diff --check` 通过。人工 UI 核对 900/1144/1440px 宽度、单行/双行工具栏、左右滚动、深色模式、表格上下文和 HSB 输入聚焦；900px 与 1440px 界面无新增页面横向溢出。主服务实测文件图标 20px、下拉箭头 18px、底部大纲图标 20px。

本次证据保存在 [icon-sizing-evidence](icon-sizing-evidence/)，包含尺寸实测、回归 JSON、构建记录及界面截图。上文 397 项 Node 与 102 项浏览器结果属于此前图标迁移，本次样式调整未重复执行全部测试。
