# M8 · 历史版本

日期：2026-10-01。文档库增加历史版本入口，提供手动检查点、只读预览、恢复和另存副本。历史属于当前浏览器的本地文档，不新增运行依赖。

## 使用与保存范围

在「文档库」找到文档，打开「历史版本」。填写可选说明后点击「保存检查点」，保存当时的标题、正文、纸张设置、图片和附件。当前文档会先等待自动保存队列提交最新输入，再生成检查点。

每个检查点独立保留引用资源，随后在当前正文中删除图片或附件，不影响旧版本。预览使用独立的只读编辑器，不替换当前正文、不共享撤销历史，也不连接自动保存队列。

「恢复此版本」需要确认。恢复事务先保留当前文档的检查点，再以旧快照替换标题、正文、纸张和资源。当前文档恢复后重建编辑会话，正文撤销历史重新开始；若需回到恢复前内容，可预览并恢复自动保留的版本。

「另存副本」创建独立文档，标题添加「 - 历史副本」，图片和附件随副本保存。当前会话不切换，可随后从文档库打开副本。

## 存储与失败保护

沿用 IndexedDB `mewoc` v1。历史元信息与快照使用 `${documentId}:history:${versionId}`，历史资源使用 `${documentId}:history-asset:${versionId}:${assetId}`；当前资源仍使用 `${documentId}:${assetId}`。三个键空间互不覆盖，旧文档无需数据库升级。

检查点、恢复及另存均在同一个文档与资源读写事务内验证来源状态和存储版本。缺失资源、版本冲突或容量不足会中止事务；恢复前的自动检查点和恢复结果一起提交或一起回滚，不留下半份恢复内容。

当前文档写操作共享现有保存与切换互斥锁。写入失败保留原编辑会话和弹窗输入，恢复原有编辑状态。预览加载、关闭、切换版本和组件卸载均处理迟到结果，临时图片与附件地址按预览会话释放。

## 限制

- 仅明确保存检查点或恢复旧版本时创建历史；普通自动保存不会为每次输入生成副本。
- 历史不会自动裁剪，也不提供永久删除入口。它继续占用本地容量，存储空间不足时操作明确失败。
- 回收文档仍保留历史，需先在回收站恢复文档，再查看历史版本。
- 历史随原文档保存在当前浏览器，清除站点数据会同时清除它们；重要内容仍应导出备份。
- Mewoc、Word 等文件导出只包含当前文档。若需带走旧版本，先另存副本，再通过编辑器导出。
