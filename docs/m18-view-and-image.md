# M18 · 图片替换与格式标记

日期：2026-10-04。本批补齐图片内容替换与编辑视图中的不可打印字符提示，完整模式和极简模式共用状态及命令。

## 图片替换

选中正文图片，在「插入 → 替换图片」选择 PNG、JPEG 或 WebP。替换沿用当前图片的宽高、左中右对齐、比例锁定、替代文本及说明，仅更新图片资源；如需适配新图比例，可继续使用「图片设置 → 恢复原始比例」。

文件选择前固定原图目标。等待读取时，正文前方编辑会映射目标；改变选区不会把新图写入另一张图片。原图删除或被替换、只读、切换文档、组合输入和会话卸载都会使任务永久失效，即使随后撤销删除或恢复编辑，也不会提交旧文件。

替换与图片插入、附件共用资源任务锁。读取期间禁用重复替换、图片设置和删除，取消或失败不改变正文；成功替换可独立一步撤销/重做。

单图最多 5 MiB，正文资源合计最多 20 MiB。容量按替换后的去重引用计算；旧图仍被其他节点引用时继续计费。新旧 Blob 和临时 URL 留在当前会话供撤销使用，持久保存和 Mewoc/HTML/Word 导出只包含当前正文实际引用的资源。撤销后再次保存可恢复原图字节。

## 格式标记

在「视图 → 格式标记」启闭，默认隐藏。当前浏览器记住开关偏好并同步其他标签页；它不属于文档内容，不增加修改序号、不触发自动保存，也不进入正文撤销历史。

| 内容 | 屏幕标记 |
| --- | --- |
| 正文和标题段落结束，包括列表、待办和表格内段落 | ¶ |
| 软换行 | ↵ |
| 普通空格 | 点 |
| 不换行空格 | 空心圈 |
| Tab 字符 | 箭头 |

代码块、行内代码及公式/图片/附件等独立节点不增加标记。符号由 ProseMirror 装饰和屏幕样式绘制，不新增原文字符、尺寸或行高。只读预览暂时隐藏，恢复编辑后沿用开关；输入法候选期间只映射既有装饰，结束后刷新。

Mewoc 文件、静态 HTML、Markdown、Word、纯文本、剪贴板和打印保留原文，不包含屏幕标记或视图偏好。实际原文若本身含有 ¶ 或 ↵，仍作为普通文字保留。
