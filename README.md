# Mewoc

参考 Umo Editor 核心体验独立实现的桌面文档编辑器。React 17 + Tiptap 3 + Ant Design 5 + Zustand，使用 Rsbuild 构建，全部应用源码使用 JavaScript / JSX。首期功能与 M6 七项扩展已实现；M5 当前版本验收已收口，结果见[收口记录](docs/m5-closure.md)。

应用图标统一使用 Tabler Icons（`@tabler/icons-react` 3.48.0）的 Outline 风格，按图标静态导入。工具栏、文件操作、批注、搜索、弹窗、分页和加载状态共用尺寸规则。项目已移除 `@ant-design/icons` 直接依赖；锁文件及许可清单仍保留 AntD 组件包要求的间接依赖。迁移范围与验证见 [Tabler 图标记录](docs/tabler-icons.md)。

## 本地运行

支持 Node.js 18.18+（18.x）、20.9+（20.x）或 21.1+，pnpm **10.34.5**；版本以 package.json、pnpm-lock.yaml 为准。Node 18 用户需要使用 pnpm 10，pnpm 11 无法在 Node 18 上启动。已在 Node 18.18.0 全新安装目录验证测试和构建；兼容说明见 [Node 18 调整记录](docs/node18-compatibility.md)。

```sh
pnpm install --frozen-lockfile
pnpm dev --port 4177
```

打开 http://127.0.0.1:4177 。文档按浏览器和访问源保存在 IndexedDB；更换端口、浏览器或清理站点数据不会共享原来的本地文档。跨设备或独立备份请导出 `.mewoc.json`，文件包含当前文档引用的图片、附件及音视频原始资源。

```sh
pnpm lint
pnpm test
pnpm build
pnpm preview --port 4178
pnpm licenses:collect
```

局域网访问时先构建，再监听全部网卡：

```sh
pnpm build
pnpm preview --host 0.0.0.0 --port 4180
```

同一局域网设备打开启动输出中物理网卡对应的 `Network` 地址。文档仍按设备、浏览器与访问源分别保存在本地，不会自动同步；跨设备使用 Mewoc 文件传递。普通 HTTP 的 ID 生成兼容修复及验证见[局域网访问记录](docs/lan-access.md)。

## 已实现

- 新建、打开 Mewoc 文件、文档库（标题搜索、排序、分页、重命名、复制、回收与恢复）、标题、自动/手动保存、刷新恢复上次打开文档、版本冲突提示。
- 历史版本：手动保存带图片和附件的检查点，只读预览、恢复或另存副本；恢复前自动保留当前版本。
- 文档模板：内置会议纪要、项目周报和工作报告；当前文档可保存为自定义模板，支持只读预览、搜索、重命名、删除和新建独立文档，保留图片与附件、清除原稿批注。
- 本地批注：选中文字添加意见，支持定位、编辑、解决、重新打开和删除撤销；随文档及历史版本保存，导出保留批注说明。
- 文字格式、字体、字号、颜色、背景色、H1–H6、段落行距/对齐、列表、链接、撤销/重做。
- 基础编辑增强：互斥上下标；数字/大小写字母/大小写罗马编号及起始号；可勾选、嵌套和独立撤销的待办清单。完整/极简模式均可用，保存、复制粘贴与导出已接入，格式差异见[基础编辑记录](docs/m17-basic-editing.md)。
- 参考 Umo 演示的段落样式卡片：正文/H1–H3 常驻、H4–H6 展开选择，支持键盘导航、当前样式回显和混合选区；聚焦段落浅底及文字选区蓝色仅出现在编辑视图。
- 格式刷：单次/连续复制文字与段落样式，保留目标链接和结构；Esc 退出，每次格式变更可独立撤销。
- 段落缩进：首行 0–4 字符、左侧 0–8 字符，支持多段设置、混合状态、格式刷、保存与 HTML/打印输出。
- 段落精细设置：段前/段后 0–120 pt 间距，按 0.5 pt 调整；支持与下段同页、段内不分页、多段混合设置、恢复默认及保存导出。
- 界面主题：视图中切换浅色、深色、跟随系统；自动保存偏好并同步其他标签页，文档纸张保持白底。
- 公式：行内/独立 LaTeX 公式，支持预览、选中编辑、删除和撤销；源码随文档保存，HTML/打印输出内嵌 MathML。
- 代码块：纯文本及 JavaScript、HTML、CSS、JSON、Bash、Python 高亮；语言选择、整行缩进、继承缩进换行、退出正文和撤销，保存/复制/HTML 输出保留源码与语言。
- Word 导入：预览 DOCX 后新建文档，保留编号续编、多段列表项、常用可编辑公式、图片与合并表格；恢复 A3/A4/A5/Letter 横竖版、四边页边距及 Mewoc 自有文字水印、页眉页脚与页码。不支持的复杂内容明确拒绝，详见[导入记录](docs/m7-docx-import.md)、[页面往返说明](docs/m22-word-page-roundtrip.md)及[页眉页脚说明](docs/m23-page-furniture.md)。
- Markdown：选择 UTF-8 文件或粘贴源码，预览转换后新建文档；导出前查看实际源码和转换说明，支持代码块、公式及普通 GFM 表格。
- 本地图片插入/粘贴/拖入，精确宽高、比例锁定、恢复原始比例、左中右对齐、替代文本与说明；选中后可替换图片，沿用排版及说明，一步撤销/重做。表格增删行列、合并/拆分、表头，精确列宽、最小行高、底色、垂直对齐、内边距和整表边框。
- 表格插入：10 列 × 8 行网格预览及键盘选择，自定义最多 100 行、20 列且不超过 1000 格，首行表头可关闭；保留原插入目标，格内光标在原表之后新建，每次可独立撤销。详见[表格插入记录](docs/m16-table-insert.md)。
- 文本框与折叠详情：正文流式富文本容器，支持文本框颜色、边框和内边距、详情标题、折叠导航、退出和保留内容移除；保存、复制及文件导出已接通。打印完整展开详情，Word 文本框转为保留外观的单格表格，详见[容器使用与转换说明](docs/m19-rich-blocks.md)。
- 文档导航：正文目录随 H1–H6 标题自动更新；段落和标题可添加命名书签，文字链接可定位到文档中的标题或书签。支持原位置设置、撤销、保存及复制目标重映射，HTML 与 Word 保留可点击的内部链接；Word 目录为静态快照，详见[目录与书签说明](docs/m20-document-navigation.md)。
- 快捷文字插入：7 种本机日期时间格式、32 个特殊字符、24 个表情；按原文字选区插入或替换，每次可独立撤销。日期时间保存为普通文本，不自动更新。
- 全选与字数统计：查看正文及当前选区的字符（含/不含空白）和段落数，支持表格内段落；只读时仍可使用，不作分词字数统计。
- 附件：选择本地文件插入下载卡片，支持保存恢复、只读下载、删除撤销及 Mewoc 文件往返；HTML 内嵌附件下载数据。
- 音频与视频：本地 MP3/WAV、MP4/WebM 插入，原生播放、暂停与进度定位，只读播放/下载、删除撤销、保存重开、历史与模板；Mewoc 和 HTML 保留原字节，Word、Markdown、纯文本和打印保留文件说明。详见[媒体说明](docs/m24-media.md)。
- 页面排版：A3/A4/A5/Letter 横竖版，常规/窄/宽边距预设及四边自定义，文字水印的文字、颜色、不透明度和角度；保存、历史、模板与导出共用页面设置。详见[页面与水印说明](docs/m21-page-settings.md)。
- 页眉、页脚与页码：单行普通文字、左中右对齐及当前页/总页数，编辑纸面使用当前分页结果，网页与小型预览显示示意，支持的浏览器打印和 Word 各自使用真实页面计数；Mewoc 自有格式可导回。保存、历史、模板与备份保留设置，详见[页眉页脚说明](docs/m23-page-furniture.md)。
- 按正文块实测的自动分页、逐页水印与页眉页脚、编辑页码与总页数、超高内容完整展开；50%–150% 缩放、适应宽度、手动分页符、大纲、字符统计、查找替换、只读。
- 跨页表格：按完整行组换页，纵向合并格与连锁跨度保持完整，续页静态重复起始连续表头；跨页编辑、选格、列宽调整与撤销仍使用原始表格，超高行组完整展开。详见[表格分页说明](docs/m25-table-pagination.md)。
- 段内分页：顶层普通段落与 H1–H6 按真实文字行跨页，保留原始段落、首行缩进、文字标记及撤销；显式「段内不分页」保留完整展开页。详见[段落分页说明](docs/m25-paragraph-pagination.md)。
- 长列表与嵌套容器分页：无序、有序和待办列表按原项目跨页，项目内长段落按行延续；引用、文本框、展开详情递归分页，源码按原换行续页，保留原编号、勾选状态和资源节点。详见[容器分页说明](docs/m25-container-pagination.md)。
- 格式标记：显示段落结束、软换行、空格、不换行空格与 Tab，开关作为浏览器偏好保存；只读暂时隐藏，文件、复制和打印保持原文。详见[图片与视图增强](docs/m18-view-and-image.md)。
- 含图片与附件的 JSON、Word（DOCX）、静态 HTML、纯文本导出，以及独立打印文档入口。

工具栏提供「极简模式」和「完整模式」：极简模式通过分组下拉选择工具，当前组工具、保存状态与模式切换排为单行；完整模式保留七个标签与双行工具。七组为开始（文字与段落格式）、插入（图片、附件、音频、视频、表格、文本框、折叠详情、目录、书签、链接、公式、日期时间、字符与表情）、表格（建表与表格设置）、工具（查找替换、批注、全选与字数统计）、页面（纸张规格、方向、边距、文字水印、页眉页脚与页码）、视图（主题、大纲、格式标记、缩放与只读）、导出（各类文件与打印 / PDF）。右侧「切换工具栏」保存当前浏览器的模式偏好，默认完整模式；宽度不足时，左右箭头可滚动查看更多工具。切换分组或模式保留已经打开的设置草稿和导出确认，关闭临时弹层。详见[工具栏模式与快捷工具](docs/m15-toolbar-modes.md)。

图片支持 PNG/JPEG/WebP；附件通过本地文件选择器插入，保留原始字节，只提供下载。音频支持 MP3/WAV，视频支持 MP4/WebM；实际播放取决于浏览器可用的编解码器。图片、附件或音视频单个最多 5 MiB，文档资源合计最多 20 MiB，Mewoc 文件最终 UTF-8 大小最多 32 MiB；外链资源不自动下载。编辑区已接入段落按行分页、表格安全行组跨页与重复表头、长列表和嵌套容器分页；M25 持续验收与版本收口仍待后续。显式不分页、含行内原子节点、双向文字等不能安全拆分的段落和超高行组完整显示在加高纸面。编辑页数不等于打印物理页数，HTML 打印和 DOCX 独立排版；协作、AI 和修订尚未接入。打印由浏览器控制，可在系统打印窗口选择另存 PDF。启用文档页眉页脚时，入口会检测页面边距框支持；不支持的 Safari/Firefox 等浏览器会停止该次打印，并建议使用支持的 Chrome 或导出 Word。请关闭系统自动页眉页脚，核对所选纸型、方向和背景选项；未启用文档页眉页脚时，Safari 仍可能需要在系统窗口选择横排。

保存停顿为 800 ms，连续输入最长等待约 5 s；成功状态明确为“已保存到此浏览器”。写入失败保留编辑内容，仍可尝试导出文件。冲突时先导出当前副本，再刷新读取存储版本；导入导出的文件会生成新的文档 ID。浏览器关闭/崩溃前的最后一次输入不保证已经落盘。

## 代码入口

```text
rsbuild.config.js                    React / Sass 插件、HTML 与开发验收入口
src/main.jsx                         React 17 入口、AntD 5 中文与主题配置
src/pages/editor/EditorPage.jsx       本地文档加载与会话切换
src/pages/editor/components/          工具栏、纸张、表单和领域 Context
src/pages/editor/hooks/               保存、图片、附件、音视频、选区、输入生命周期
src/pages/editor/tools/               Schema、IndexedDB、快照、文件与打印
src/pages/editor/extensions/          图片、附件、音视频、表格列宽、格式刷、段落行距、自动分页、公式、代码块
src/pages/editor/sass/                Sass CSS Modules 与内容样式
tests/                               自动化与浏览器验收
```

Tiptap 是正文、选区与正文撤销的唯一所有者；Zustand 按编辑器实例创建，保存标题、纸张、界面状态和 revision。没有后端、账号或虚构保存接口。服务端适配契约保留在实施方案中，尚未实现宿主 SDK。
